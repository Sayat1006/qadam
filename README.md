# Qadam: білім беру платформасы

6–15 жастағы балаларға арналған веб-платформа. Әр бала өз қарқынымен оқиды: тапсырмалар баланың жасына емес, **өз деңгейіне** қарай бейімделеді.

> Сайт мәтіндерінде балаға немесе ата-анаға таңба болатын сөздер («инклюзивті», «ерекше бала» және т.б.) қолданылмайды. Бейімделу байқалмайтындай болуы керек, әр бала үшін қалыпты оқу ортасы.

## Мүмкіндіктер (MVP, 1-кезең)

| Бөлім | Не бар |
|---|---|
| **Пәндер** | Математика, Қазақ тілі, Дүниетану, Өмірлік дағдылар, Ағылшын тілі. Әр пәнде 5 деңгей (🌱 Тұқым → 🌿 Өскін → 🌳 Бәйтерек → 🐎 Тұлпар → 🦅 Қыран). Қалған пәндер «Жақында» тізімінде. |
| **Тапсырма түрлері** | Таңдау, сан енгізу (экрандық пернетақта), ретімен қою, топқа бөлу, жұптастыру. Бәрін тек басу арқылы орындауға болады, сүйреп апару қажет емес. |
| **Бейімделу** | Әлсіз тақырыптар жиірек шығады. Әр сабаққа алдыңғы деңгейден бір қайталау тапсырмасы қосылады. Келесі деңгейге өту үшін соңғы 6 тапсырманың 5-еуін бірінші реттен орындау керек. Бастапқы деңгей тым жеңіл болса, «жылдам жол» бар. Деңгей ешқашан автоматты түрде төмендемейді: оның орнына ересектерге «көмек керек» белгісі шығады. |
| **Бота жетекші** | 3 сатылы кеңес береді (еске салу → жетелеу → көрсету). 2 қатеден кейін тапсырманы жеңілдетеді, 3 қатеден кейін дұрыс жауапты көрсетеді. Сондай-ақ көңіл-күйді сұрайды, үзіліс жасауды еске салады және «Бүгінгі 3 қадам» жоспарын ұсынады. |
| **Ойындар** | Жұбын тап, Әріп керуені, Киіз үй тұрғыз, Сауда базары (теңгемен). Ұтылу жоқ. |
| **Марапат** | Жұлдыздар бірінші реттен табылған жауап үшін ғана емес, еңбек үшін де беріледі. Жұлдызға «Менің ауылым» безендіріледі. Балаларды бір-бірімен салыстыратын рейтинг жоқ. |
| **Тыныштық бұрышы** | Тыныс алу жаттығуы. |
| **Ата-ана панелі** | Оқу уақыты, апталық график, дәлдік, қарапайым тілмен жазылған қорытынды, көңіл-күй күнделігі, үйде көмектесу кеңестері, уақыт шегі, баланың қолжетімділік баптаулары. |
| **Мұғалім кабинеті** | Оқушылар кестесі (деңгей, дәлдік, «көмек керек» белгісі), деңгейді қолмен өзгерту, ұсынылған пән, ата-анамен ортақ жазбалар. |
| **Әкімші** | **Тіркелгіні тек әкімші ашады**: ата-ана, мұғалім, бала. Әкімші баланы ата-анасы мен мұғаліміне байланыстырады, құпиясөзді өзгертеді, деректердің сақтық көшірмесін жасайды. |
| **Көрініс пен дыбыс** | Әріп өлшемі 100–200%, 4 түс тақырыбы (жоғары контраст пен қараңғы тақырып бар), оқуға жеңіл қаріп, дауыстап оқу (TTS), анимацияны өшіру, қарапайым интерфейс. Толық пернетақтамен басқару. Оқи алмайтын балаларға сурет-құпиясөз. |

## Дизайн

QADAM дизайн жүйесі (`src/styles.css`, `src/components/kit.tsx`):

- **Палитра:** Deep Navy `#101B3D`, Indigo `#5145D8`, Electric Blue `#4388FF`, Soft Violet `#9275FF`, Cyan `#65D8F2`, Green `#35C98A`, Warm `#FFCA70`.
- **Тақырыптар:** Авто (жүйе бойынша), Жарық, Қараңғы, Жоғары контраст. Таңдау сақталады.
- **Қаріп:** Inter (қазақ кириллицасы толық).
- **3D:** бастапқы беттегі hero сахнасы — three.js (`src/three/heroScene.ts`). Тек компьютерде, WebGL болғанда және анимация өшірілмегенде динамикалық жүктеледі; көрінбей тұрғанда рендерлеу тоқтайды. Телефонда және қалған жағдайда — жеңіл CSS-3D нұсқасы.
- **Анимация:** CSS (150–250 мс микро-әрекет, 300 мс карточка, 400 мс бет). `prefers-reduced-motion` пен «Анимацияны өшіру» баптауы ескеріледі.
- **Жетістіктер:** `src/lib/achievements.ts` — белгілер, серия (қатарынан оқу күндері), деңгей прогресі тек сақталған нақты деректерден есептеледі.

## Іске қосу

```bash
npm install
npm run dev      # әзірлеу сервері
npm run build    # өндірістік жинақ (dist/)
npm run check    # барлық тапсырма генераторын автоматты тексеру
```

Алғаш ашқанда сайт әкімші тіркелгісін құруды сұрайды.

Vercel-ге жариялауға дайын (`vercel.json`): Framework — Vite, Output — `dist`.

## Архитектура

```
src/
  content/   пәндер мен тапсырма генераторлары (math, kazakh, world, life, english)
  lib/       деректер қабаты (db.ts), бейімделу алгоритмі (adaptive.ts), TTS/дыбыс
  components/ TaskView (тапсырма түрлері), Visual, A11y панелі, Бота
  games/     ойындар
  pages/     бала аймағы, ата-ана/мұғалім/әкімші панельдері
```

Тапсырмалардың көбі **генератор** арқылы жасалады. Сондықтан бала бір тапсырманы жаттап алмайды: әр сабақта сандар, сөздер мен нұсқалар жаңарып отырады.

## Маңызды ескерту: деректер

MVP-де барлық дерек **осы құрылғының браузерінде** (localStorage) сақталады, құпиясөздер SHA-256 хэшімен сақталады. Бұл пилоттық тестке және бір құрылғыда жұмыс істеуге жарайды. Нақты мектепке енгізу үшін 2-кезеңде `src/lib/db.ts` Supabase-пен ауыстырылады. Сонда:

- тіркелгіні тек әкімші ашады, бұл серверде тексеріледі (service role арқылы Edge Function);
- рөлдер Row Level Security арқылы бөлінеді: ата-ана тек өз баласын, мұғалім тек өз оқушыларын көреді;
- деректер құрылғылар арасында синхрондалады.

## Келесі кезеңдер

1. Supabase: бұлттағы тіркелгі, RLS, көп құрылғы.
2. Қалған бастауыш пәндер, мұғалімге арналған тапсырма конструкторы, PWA (офлайн).
3. 5–9 сынып пәндері, ЖИ-жетекші (Claude API, серверлік прокси), Жеке дамыту бағдарламасы (ЖДБ), PDF-есептер, ым тілі бейнелері.
4. Мұғалімдер мен ата-аналардың қатысуымен пилоттық тестілеу.
